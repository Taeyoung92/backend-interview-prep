## 알고있는 AI 도구 장단점/특징/소감

**NotebookLM**
용도 : 본인이 업로드한 문서/자료를 기반으로 한 학습/연구 보조. 업로드 한 문서 등을 소스로 삼아 그 안에서만 답변하는 RAG 기반 도구. 출처 인용이 명확하고 오디오 요약 기능이 강점
장점 : 내가 준 자료 안에서만 답하므로 환각이 적고 출처 추적이 쉬움. 방대한 자료 요약/정리에 탁월함
단점 : 외부 일반 지식 활용은 약함. 업로드한 자료가 없으면 무용지물

**Copilot**
용도 : IDE 내 실시간 코드 자동완성·생성. VS Code 등 에디터에 붙어서 코딩 중 다음 줄을 예측하고 완성. 개발 워크플로에 깊게 통합됨.
장점 : 코드 컨텍스트를 읽고 자동완성, 반복 코드 작성 속도 향상. IDE 내장
단점 : 복잡한 아키텍처 설계나 긴 추론은 약함. 잘못된 코드를 그럴듯하게 제안하기도 함

**Claude**
용도 : 긴 문맥 처리, 글쓰기·문서 작업, 코딩, 복잡한 추론. 긴 텍스트를 다루는 능력과 자연스러운 문장 생성이 강점. 문서 작성·편집, 코드 작성, 분석 등 범용적.
장점 : 긴 컨텍스트 처리 우수, 자연스럽고 정제된 글쓰기, 안전성 높음
단점 : 실시간 정보는 검색 기능 필요, 사용량 제한 존재

**Perplexity**
용도 : 출처 기반 실시간 검색·리서치. 질문하면 웹을 검색해 출처와 함께 답하는 "AI 검색엔진". 최신 정보 확인에 특화.
장점 : 최신 정보 + 출처 링크 제공으로 사실 확인 쉬움. 리서치 시작점으로 좋음
단점 : 심층 추론·창작은 약함. 출처 품질이 들쭉날쭉

**GPT**
용도 : 범용 대화·생성형 AI (코딩, 글쓰기, 이미지, 음성 등). 가장 널리 쓰이는 범용 도구. 플러그인·이미지 생성·음성 등 기능이 폭넓고 생태계가 큼.
장점 : 범용성·생태계 최강, 멀티모달(텍스트/이미지/음성) 지원, 자료·예제 풍부
단점 : 환각 발생 가능, 사실성은 별도 검증 필요

**Genspark**
용도 : AI 에이전트 기반 검색·작업 자동화. 여러 AI를 조합해 검색 결과를 "Sparkpage"로 종합 생성하고, 에이전트가 작업(예약, 정보 수집 등)을 수행하는 방향.
장점 : 검색 결과를 페이지로 종합, 에이전트형 작업 자동화 시도
단점 : 비교적 신생 서비스로 안정성·검증 부족, 결과 신뢰도 편차

**Gemini**
용도 : 구글 생태계 통합 범용 AI (검색, Workspace, 안드로이드). Gmail, Docs, 검색 등 구글 서비스와 깊게 통합. 멀티모달과 긴 컨텍스트 지원.
장점 : 구글 서비스 연동, 멀티모달, 긴 컨텍스트, 실시간 검색 통합
단점 : 답변 일관성 편차, 일부 기능 지역·계정 제한

**Codex**
용도 : 코드 생성·자동화 (현재는 에이전트형 코딩 도구). 원래 Copilot의 기반 모델명이었으나, 현재는 OpenAI의 에이전트형 코딩 도구 이름으로 쓰임. 작업을 위임하면 코드베이스에서 자율적으로 작업 수행.
장점 : 코드 작업 위임·자동화, 여러 파일에 걸친 작업 처리
단점 : 자율 실행이라 결과 검토 필수, 복잡한 의도 파악은 한계

**Vercel v0**
용도 : 자연어로 프론트엔드 UI·컴포넌트 생성. 텍스트 설명만으로 React/Tailwind 기반 UI를 생성하는 도구.
장점 : 프롬프트만으로 동작하는 UI 코드 생성, 프로토타이핑 초고속
단점 : 디자인·로직 세밀 제어 한계, 복잡한 앱은 추가 개발 필요

## AI가 할수 없는 일이나 하면 안되는 일은?
1. 사실의 보증 - AI는 그럴듯한 답을 생성할 뿐 사실을 검증하지 못함. 존재하지 않는 라이브러리 함수나 API를 자신있게 만들어내기도 하므로 반드시 직접 실행 및 테스트가 필요하고, 공식 문서로 교차 검증이 필요함
2. 맥락 및 의도 파악 - 조직의 히스토리, 암묵적 컨벤션, 비즈니스 배경, 레거시 코드가 짜여진 이유 등은 알지 못하고 표면적인 코드만 보고 판단
3. 책임 - 장애가 났을 때 책임지지 못함.
4. 검증 없는 코드의 반영 - 보안 취약점이 섞인 코드를 그대로 배포할 수도 있음
5. 라이선스/저작권 무시 - AI로 생성한 코드에는 라이선스 문제가 있을 수 있어, 상업적으로 쓰면 위험

>> AI는 생산성을 높이는 도구이지만, 사실 검증/맥락 판단/책임은 못함.
